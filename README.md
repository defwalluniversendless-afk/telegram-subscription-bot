# Бот платной подписки на закрытый Telegram-канал

Бот принимает оплату через ЮKassa, выдаёт одноразовую ссылку в закрытый канал, напоминает о продлении и закрывает доступ после окончания подписки.

## Подготовка

1. Создайте бота через @BotFather и получите `BOT_TOKEN`.
2. Добавьте бота администратором закрытого канала с правами приглашать и блокировать пользователей. Укажите `CHANNEL_ID` (обычно начинается с `-100`) и свой Telegram ID в `ADMIN_ID`.
3. Для настоящих оплат настройте магазин ЮKassa и получите `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET`.
4. Создайте локальный `.env` из шаблона и заполните параметры:

   ```sh
   cp .env.example .env
   ```

   **Не добавляйте `.env` в Git и никому не отправляйте его:** файл содержит токен Telegram и ключ ЮKassa. В репозитории хранится только `.env.example` без секретов.

## Запуск

```sh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Для настоящих тестовых платежей через ЮKassa возьмите тестовые `shop ID` и секретный ключ в кабинете ЮKassa в разделе тестового магазина/API-ключей и задайте их в переменных окружения (`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET`). При этом укажите `TEST_MODE=0`: бот создаст платёж в ЮKassa и получит подтверждение об оплате. Не используйте здесь ключи рабочего магазина, если хотите тестировать без списания реальных денег.

`TEST_MODE=1` — отдельный режим локальной имитации без ЮKassa: оплатить сможет только администратор, и реального тестового платежа не будет. Для рабочих оплат также укажите `TEST_MODE=0`, но используйте ключи рабочего магазина. После изменения переменных окружения перезапустите бота. Для постоянной работы запустите бота на сервере или другой подходящей хостинг-платформе: сам GitHub не запускает этот бот.

## Команды

- Пользователи: `/start`, `/status`, `/cancel`.
- Администратор: `/users` (список и управление подписками), `/grant ID дни` (выдать доступ вручную), `/del @username` или `/del Telegram_ID` (сбросить подписку и удалить пользователя из канала), `/all текст` (рассылка всем), `/all_sub текст` (рассылка активным подписчикам), `/block @username` или `/block Telegram_ID` (заблокировать в боте и удалить из канала), `/unblock @username` или `/unblock Telegram_ID` (снять блокировку), `/stats`.

В `/users` администратор может посмотреть пользователей и срок подписки, продлить подписку на 30 дней, установить срок окончания через произвольное число дней от текущей даты или сбросить подписку и удалить пользователя из канала. Кнопка «Написать пользователю» позволяет начать переписку: ответьте на запрос бота текстом или медиа; пользователь может отвечать реплаем на сообщения бота, а администратор — реплаем на полученные ответы. Связи сообщений хранятся в базе и сохраняются после перезапуска. Список разбит на страницы; команда и кнопки управления доступны только администратору.

Бот уведомляет администратора о каждой успешной оплате и раз в день присылает число новых пользователей за текущий день (время UTC). Пользователи с активной подпиской при `/start` и `/status` видят статус и кнопку связи; продлить подписку можно кнопкой из напоминания. Ручная успешная оплата добавляет период к текущей дате окончания, не обнуляя оставшиеся дни.

Автосписание работает отдельно от ручного продления: задайте `AUTOCHARGE=1`, используйте `TEST_MODE=0` и ключи нужного магазина ЮKassa. Первая оплата должна сохранить способ оплаты (`payment_method.saved=true`); без его ID бот не сможет создать повторный платёж. Если включили автосписание уже после первой оплаты, понадобится новая оплата с сохранением способа оплаты. При попытке списания бот проверяет платёж у ЮKassa; ошибки проверки и отменённые повторные платежи записываются в журнал, а пользователь получает сообщение о неудачной попытке. `/stats` показывает число активных подписок с сохранённым способом оплаты и ожидающих автоплатежей. Успешная ручная оплата по кнопке продления прибавляет срок к оставшейся подписке.

`/block` не может запретить человеку снова открыть чат с ботом на уровне Telegram: он сохраняет пользователя в базе как заблокированного, блокирует обработку его сообщений и кнопок и удаляет из канала. Запись остаётся для истории; администратор может снять ограничение через `/unblock`.
