# Бот платной подписки на закрытый Telegram-канал

Бот принимает оплату через ЮKassa, выдаёт одноразовую ссылку в закрытый канал, напоминает о продлении и закрывает доступ после окончания подписки.

## Подготовка

1. Создайте бота через @BotFather и получите `BOT_TOKEN`.
2. Добавьте бота администратором закрытого канала с правами приглашать и блокировать пользователей. Укажите `CHANNEL_ID` (обычно начинается с `-100`) и свой Telegram ID в `ADMIN_ID`.
3. Для настоящих оплат настройте магазин ЮKassa и получите `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET`.
4. Создайте локальный `.env` из шаблона и заполните параметры:

   ```sh
   cp .env.example .env
   ```

   **Не добавляйте `.env` в Git и никому не отправляйте его:** файл содержит токен Telegram и ключ ЮKassa. В репозитории хранится только `.env.example` без секретов.

## Запуск

```sh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Для тестового режима укажите `TEST_MODE=1`; для рабочих оплат — `TEST_MODE=0` и заполните учётные данные ЮKassa. Для постоянной работы запустите бота на сервере или другой подходящей хостинг-платформе: сам GitHub не запускает этот бот.

## Команды

- Пользователи: `/start`, `/status`, `/cancel`.
- Администратор: `/grant ID дни` (выдать доступ вручную), `/stats`.
